Source delivery and limitations
-------------------------------

Conservative implementation direction: preserve both unmodified complete Eigen
source archives, their hashes, all COPYING files (including APACHE), all file
copyright/license notices, and an explicit source-availability notice alongside
the distributed image. Match any actual Eigen source modifications and expose
those modifications under their applicable source license. This addresses the
source-delivery portion; it does not by itself establish compliance if LGPL
code was compiled. In that case, determine the applicable relinking/build/source
requirements or replace/rebuild only with separately verified authorization.
